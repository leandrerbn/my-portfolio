Hireloop

A job board platform dedicated to publishing job offers and enabling direct matching between recruiters and candidates.

Role / Context Full-Stack Development
Team Collaborative Project (3 Devs)
Stack Laravel, REST API, SQL, JS
Status Completed

Overview & Objectives

Hireloop was designed to centralize job and internship offers on a single platform to simplify their consultation.

The architecture delivers secure, dedicated spaces: a candidate portal for quick applications, a recruiter dashboard for centralized offer and applicant tracking, and an administrator core for complete data management.

01 — Candidate Application Modal

02 — Recruiter Dashboard & Profile

03 — Job Offer Creation Interface

04 — Offer Management & Applicants Overview

Technical Details

Developed with a responsive front-end communicating via HTTP/JSON with a robust Laravel REST API back-end, utilizing Eloquent ORM for efficient SQL database management.
